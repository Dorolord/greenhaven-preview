# GreenHaven — мобільна тестова версія 🌿

Цей публічний репозиторій призначений **лише для тестування інтерфейсу** GreenHaven на телефоні через GitHub Pages.

Поточна підготовлена збірка: **v297** (ферма, нижня навігація, XP і склад із затверджених окремих елементів (рамка, комірка, хрестик, повзунок) і реальною прокруткою). Для складу додано окремі затверджені іконки моркви, пшениці й гарбуза; за збір моркви та пшениці видається по 4 шт., гарбуза — 1 шт. Баланси зберігаються локально в браузері. Ігровий бекенд, Telegram-авторизація, реальні платежі і серверне збереження прогресу тут не налаштовані.

## Як оновлювати

Завантажити до кореня репозиторію `index.html` та всю папку `assets/` з підготовленого ZIP. Потім у **Settings → Pages** вибрати `Deploy from a branch`, `main`, `/(root)`.

Адреса після публікації: https://dorolord.github.io/greenhaven-preview/

**Важливо:** не додавати токени Telegram, паролі й рядки підключення бази даних у публічний репозиторій. Старі приватні репозиторії `GreenHaven-Game` і `GreenHaven-v03` залишаються незмінними.

## План розташування

Поточні координати ферми задані файлом `GreenHaven-layout.json` (відповідає Новий план.json; 12 об'єктів), застосовуються в `index.html` один раз для кожного браузера. Далі зміни можна робити в редакторі ферми.

## Панель ресурсів

У v272 підготовлено місце для трьох лічильників — золото, діаманти й Green Token — у стилі схваленого арту. Для відображення потрібно один раз завантажити `assets/gh-resources-approved-v272.webp` з підготовленого файлу; до появи цього файлу старі лічильники залишаються на місці. Числа 1 250, 25 та 0 поки демонстраційні й не означають реальні баланси.

## Тест економіки v275

У вкладці **Профіль → Налаштування → Тест економіки** доступні кнопки нарахування XP, золота, діамантів і Green Token, перевірка списання, одноразової винагороди та скидання тесту. Дані зберігаються локально в браузері під ключем `greenhaven-preview-economy-v275` і **не є реальними грошима чи серверним балансом**.

Початок: 1 рівень, 0/100 XP, 1250 золота, 25 діамантів, 0 Green Token. Наступний рівень потребує на 50 XP більше. При підвищенні рівня надлишковий XP переноситься. Одноразову тестову винагороду `demo-harvest-001` не можна отримати двічі.

Всі дії нарахування зараз лише тестові: вирощування, продаж і реальні нагороди ще не підключені до серверної економіки.

**v276:** Замінено малюнок верхньої панелі ресурсів на `assets/gh-resources-empty-v276.webp` без намальованих цифр. Баланси відображаються окремими прозорими HTML-елементами поверх нього; геометрію панелі не змінено.
